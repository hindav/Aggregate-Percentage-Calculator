



#  Aggregate Percentage Calculator

A simple web-based tool to calculate your **aggregate percentage from marksheets** quickly and accurately. Enter total and obtained marks for subjects or semesters and instantly get your overall percentage.

## 🚀 Features
- Calculate overall percentage easily  
- Add multiple subjects dynamically  
- Fast and accurate calculation  
- Simple and clean user interface  
- Helpful for students and academic records  

---

## 🖥️ How It Works
1. Enter **Total Marks** and **Obtained Marks**.  
2. Use **Add Subject** if you have multiple subjects.  
3. Click **Calculate Percentage**.  
4. Your aggregate percentage will be displayed instantly.
